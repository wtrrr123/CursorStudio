# 光标工坊 2.2

适用于 Windows 10 / 11 x64。双击 CursorStudio-Setup-x64.exe 完成安装，再从开始菜单打开 Cursor Studio。运行环境已内置。
默认安装到安装程序所在目录下的 CursorStudio 子文件夹，也可在安装界面选择位置。

- 从左侧选择一个光标状态，再导入 PNG、WebP、GIF 或 JPG。源图片上限为 40 MB 和 5000 万像素，导入后最长边保留至 2048 像素。动画图片取首帧。
- 输出可选 32、48、64、96、128、192、256 像素。实际显示尺寸可能随 Windows 和应用的设置变化。
- PNG、WebP 和 GIF 自带的透明区域会被保留。切换棋盘格、浅色或深色可检查镂空及边缘。普通照片也可用「透明橡皮擦」手动擦成透明。
- 点击或拖动预览中的十字可调整实际点击点。在试用区点击圆心，可核对落点。
- 使用「套装」菜单打开或保存 .cursorpack，或导出 .cur。新版可打开旧套装。
- 可直接应用整套。点击「恢复光标」、窗口内按 Esc、或正常关闭应用可恢复系统已配置的光标方案。强制退出后，再次打开应用会先尝试恢复。

默认启用「匹配系统光标尺寸」。应用与导出时，用高分辨率源图重采样到工坊窗口所在显示器对应的 Windows 光标尺寸。移到另一台显示器后，可再次点「应用套装」。系统级套装一次只应用一组尺寸。关闭该选项可以手动选尺寸。

「加载示例」仅供预览和试点。应用、保存和导出只使用自己导入或从套装打开的图片。未配置的状态沿用 Windows 光标。移除某个状态后，重新应用即可恢复该状态。

导入图片后点击「透明橡皮擦」，调节笔刷大小并拖动涂抹。棋盘格表示透明。可撤销最近 8 笔（Ctrl+Z），或点「取消」放弃本次编辑。「保存擦除」会保留透明区域，随后可保存套装、导出 .cur 或应用到系统。
